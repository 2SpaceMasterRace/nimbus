# Git

This chapter is split into two parts.

The first part is about Git itself: what it is, how it stores history, how commits and branches work, how to recover from mistakes, and how to solve the problems that show up when multiple people are editing the same codebase.

The second part is about GitHub: repositories, branches on a hosted remote, pull requests, review, CI, merge conflicts in shared collaboration, and the practical team workflow around code review.
