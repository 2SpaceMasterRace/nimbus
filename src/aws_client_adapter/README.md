# aws_client_adapter

HTTP-backed adapter that implements `cloud_storage_client_api` using the
autogenerated `aws_s3_cloud_storage_service_client` package.

## Role

This package is the HW2 adapter/shim. It preserves the original
`CloudStorageClient` interface while routing calls over HTTP to the FastAPI
service.

## Dependencies

- `cloud-storage-client-api` for the abstract contract and domain exceptions
- `aws-s3-cloud-storage-service-client` for the autogenerated HTTP client

## Configuration

- `CLOUD_STORAGE_SERVICE_BASE_URL` - base URL of the deployed service
- `API_KEY` - optional API key used for protected endpoints

## Usage

```python
import aws_client_adapter
from cloud_storage_client_api.factory import get_client

client = get_client()
files = client.list_files("my-bucket", "")
```
