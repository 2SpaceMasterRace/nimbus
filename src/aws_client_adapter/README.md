# aws_client_adapter

HTTP-backed adapter that implements `cloud_storage_api.CloudStorageClient` using the
autogenerated `aws_s3_cloud_storage_service_client` package.

## Role

This package preserves the original `CloudStorageClient` interface while
routing calls over HTTP to the FastAPI service.

## Dependencies

- `cloud-storage-api` (external, via git) for the abstract contract and domain types
- `aws-s3-cloud-storage-service-client` for the autogenerated HTTP client

## Configuration

- `CLOUD_STORAGE_SERVICE_BASE_URL` - base URL of the deployed service
- `API_KEY` - optional API key used for protected endpoints

## Usage

```python
from aws_client_adapter import get_client_impl

client = get_client_impl()
files = client.list_files("my-bucket", "")
```
