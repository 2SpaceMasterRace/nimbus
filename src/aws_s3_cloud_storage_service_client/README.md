# aws-s3-cloud-storage-service-client

Autogenerated OpenAPI client for `aws-client-service`.

## Role

This package is the mechanical HTTP layer generated from `/openapi.json`. It is
intentionally low-level and is typically consumed through `aws_client_adapter`,
not directly by application code.

## Usage

```python
from aws_s3_cloud_storage_service_client import AuthenticatedClient
from aws_s3_cloud_storage_service_client.api.default import list_files_files_get

client = AuthenticatedClient(
    base_url="https://ospsd-team-2.fly.dev",
    token="your-api-key",
)

response = list_files_files_get.sync(
    client=client,
    container="my-bucket",
    prefix="reports/",
)
```

## Notes

- The code inside `aws_s3_cloud_storage_service_client/` is autogenerated.
- Regenerate it from the service's OpenAPI schema instead of editing it by hand.
- Higher-level callers should prefer `aws_client_adapter`, which maps HTTP
  failures back into the abstract domain exceptions.

## Regeneration

```bash
uvx openapi-python-client generate \
  --url https://ospsd-team-2.fly.dev/openapi.json \
  --meta uv \
  --output-path /tmp/generated-client
```
